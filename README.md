# 📊 Business Insights 360 — Power BI Project
## 🚀 Overview

Business Insights 360 is an end-to-end Power BI solution built for AtliQ Hardware to enable data-driven decision-making across Finance, Sales, Marketing, and Supply Chain functions.

The project transforms scattered business data into a centralized analytics dashboard, providing stakeholders with clear performance visibility and actionable insights.

Built as part of the Codebasics Business Insights 360 Program.

## 🏢 Business Context

AtliQ Hardware, a global electronics company, expanded into new markets using manual Excel analysis and intuition, leading to financial losses.

To improve strategic decision-making and operational efficiency, the company adopted Power BI to create a structured reporting and analytics system.

## 🎯 Objectives

Build a single source of truth

Enable cross-functional performance tracking

Automate reporting processes

Provide KPI-driven insights

Improve forecasting and profitability analysis

## 🛠 Tech Stack

SQL (MySQL)

Power BI Desktop & Service

DAX & DAX Studio

Power Query (M Language)

Excel

## 📊 Key Features

Snowflake Data Model

Complex DAX measures & KPI calculations

Dynamic filtering & drill-down analysis

Conditional formatting with indicators

Bookmark-based navigation

Automated refresh via Personal Gateway

Executive summary dashboard

## 📑 Dashboard Views

Finance: P&L, Net Sales, Gross Margin, Net Profit

Sales: Customer & Product Performance

Marketing: Segment Profitability Analysis

Supply Chain: Forecast Accuracy & Demand Planning

Executive: Top Customers, Top Products, Regional Overview

## 📊 Key Power BI Implementations
The project incorporates the following Power BI development techniques and best practices:
Structured business requirement analysis before dashboard design
Development of calculated columns and advanced DAX measures
Implementation of a Snowflake schema data model
Interactive navigation using Bookmarks and buttons
Error handling using DIVIDE() for robust calculations
Custom Date table creation using Power Query (M language)
Dynamic titles and filter-based context adjustments
KPI indicators with conditional formatting (icons & color logic)
Report publishing to Power BI Service
Personal Gateway configuration for scheduled refresh
App creation and workspace management
